# Calendar tasks

Use the user's existing connected calendar tools; do not invent an integration or use another business's account. Read availability before drafting. Use the user's explicit timezone, concrete dates and intended calendar. For a new event, show the exact title, time, duration, participants and notification behavior. Sending invitations or moving meetings requires the user's approval of those details. A lookup is not an event creation. Report the actual event receipt after an approved write.
